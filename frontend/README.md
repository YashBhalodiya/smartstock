# Smart Inventory & Automated Restock Management System — Frontend

This is the frontend application for the Smart Inventory & Automated Restock Management System designed for shopkeepers.

## Technology Stack

- **React** (v19)
- **Vite**
- **JavaScript** (JSX)
- **React Router** (`react-router-dom`)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
